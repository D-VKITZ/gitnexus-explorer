## Features

| Feature | Description |
|:--------|:------------|
| Code Intelligence Graph | Force-directed visualization of code relationships across your project |
| GitNexus MCP | Model Context Protocol integration for AI-powered code analysis |
| Force-Directed Canvas | Physics-based graph layout with zoom, pan and drag |
| 20 Node Types | Functions, classes, modules, imports and dependencies visualized |
| File Tree Navigation | Hierarchical project structure with expand and collapse |
| RAG Query Engine | Natural language code search with retrieval-augmented generation |
