# GitNexus Explorer

GitNexus Explorer — Code Intelligence und Repository-Analyse.

## Features

- Repository structure visualization as interactive graph
- Code intelligence with dependency mapping
- MCP server integration for code analysis
- File explorer with search and navigation
- Multi-repository comparison

## Tech Stack

Node.js · JavaScript ES6+ · MCP Server · Canvas API

## Quick Start

```bash
git clone https://github.com/D-VKITZ/gitnexus-explorer.git
cd gitnexus-explorer
npm install
npm run dev
```
